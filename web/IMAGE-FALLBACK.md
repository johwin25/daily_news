# Illustration fallback
Top-three headlines first attempt a reasonably matched Commons JPEG. If the lookup fails or no match is found, the UI displays a predefined category photograph from Unsplash (World, Economy, Technology or Science). A styled placeholder remains available if the image service is offline. All are marked **illustrative**; they are not implied to depict the actual event.

This is a presentation improvement, not a fact-checking mechanism. Wikimedia Commons images still require per-image license/credit verification and the metadata match is only approximate. Future releases should move image resolution to a controlled build-time step that retains the exact creator, license, image origin, and story association.
